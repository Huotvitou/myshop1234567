# Neon Digital Store — Next.js + Tailwind (Vercel Ready)

## Develop
npm install
npm run dev

## Deploy to Vercel
- Import to Vercel as Next.js project (no changes required)
- Build command: `npm run build` (auto)
- Routes:
  - `/` — Home + Products grid
  - `/admin/login` — Admin login (admin/1234)
  - `/admin` — Add Product (saved to localStorage)

## Change Telegram username
- Edit the href in `pages/index.js` where `t.me/Vitouhuot` is used.
